Source-controlled research infrastructure for Native ESET.

The repository is initialized with a minimal landing page so the audited B2 `0.1.0` bootstrap can enter via a reviewable pull request. The full B2 source tree remains independently verified in the Drive release package (SHA-256 `c1577af4867f3e425db633b36bb68ade0ba48c122864787a231ec996bacdc643`).

**Scope:** Research software infrastructure; no physically validated ESET model is asserted. The sealed 31-file Theory-State graph and private observational datasets are not part of this public repository.
